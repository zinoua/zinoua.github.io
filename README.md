
# Syria's 2006–2010 Drought: A Historical and Modern Perspective

This repository hosts my CS-215 Data Science final project website. I am investigating the 2006–2010 drought using instrumental climate data, regional cave isotope records, and Syrian agricultural, water-use, and population data.

## Project website

[Visit the website](https://zinoua.github.io/)

## Project updates

- **[Week 9 – Project Directions and Proposal](https://zinoua.github.io/week9.html)**: The original project ideas, selected topic, and initial research questions.

- **[Week 11 – Data Collection and Preliminary Findings](https://zinoua.github.io/week11.html)**: Data sources, acquisition, cleaning, and preliminary results.

- **[Week 12 – Exploratory Analysis and Interactive Visualization](https://zinoua.github.io/week12.html)**: Detailed analysis of Gejkar, PDSI, CRU, FAOSTAT, AQUASTAT, and UN population data, including visualizations, sensitivity checks, and methodological limitations.
  
- **[Final Analysis – Was Syria's 2006–2010 Drought Unprecedented?](https://zinoua.github.io/final-analysis.html)**: A synthesis of the climate, agricultural, irrigation, and demographic findings, addressing the central research question and remaining uncertainties.
