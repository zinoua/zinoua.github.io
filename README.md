
# Syria's 2006–2010 Drought: A Historical and Modern Perspective

This repository hosts my CS-215 Data Science final project website. I am investigating the 2006–2010 drought using instrumental climate data, regional cave isotope records, and Syrian agricultural, water-use, and population data.
