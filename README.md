# Syria's 2006–2010 Drought: A Historical and Modern Perspective

This repository supports my CS-215 Data Science final project investigating the severity of Syria's 2006–2010 drought through modern climate observations, paleoclimate proxy records, and agricultural, water-use, and population datasets.

The project combines data from NOAA, CRU TS, FAOSTAT, AQUASTAT, and the UN Population Data Portal.
